# T.A.O Marketing System

**Think / Act / Optimize** - 考え、動き、改善する

## 概要

T.A.O Marketing Systemは、**歯科医院のWEBマーケティングを完全に網羅した統合マーケティングプラットフォーム**です。田尾耕太郎の約20年にわたる歯科業界マーケティングの知見を凝縮し、歯科医院経営者が最小限の労力で最大のマーケティング効果を得られるシステムを目指します。

- **T**hink（考える）：GA4・サーチコンソールのデータをAIが分析し、戦略を立案
- **A**ct（動く）：ポータルサイト管理の自動化、ワンクリック対応
- **O**ptimize（改善する）：継続的なスコアリングと改善提案

## 主要機能

### 1. スコアリングダッシュボード
- GA4、サーチコンソール、Googleビジネスプロフィールと連動
- SEO/MEO/アクセス/コンテンツを100点満点でスコアリング
- 総合スコアで現在の状態を一目で把握

### 2. AI分析・改善提案
- 田尾耕太郎のノウハウを学んだAIが分析
- 具体的な改善アクションを優先順位付きで提案
- 期待効果と難易度を明示

### 3. ポータルサイト掲載管理
- 主要歯科ポータルサイトへの掲載状況を自動確認
- 未掲載・要更新サイトを一覧表示
- 効率的な登録・更新をサポート
