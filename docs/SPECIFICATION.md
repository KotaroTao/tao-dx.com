## 1. システム概要

### 1.1 コンセプト

T.A.O Marketing Systemは、**歯科医院のWEBマーケティングを完全に網羅した統合マーケティングプラットフォーム**です。田尾耕太郎の約20年にわたる歯科業界マーケティングの知見を凝縮し、歯科医院経営者が最小限の労力で最大のマーケティング効果を得られるシステムを目指します。

- **T**hink（考える）：GA4・サーチコンソールのデータをAIが分析し、戦略を立案
- **A**ct（動く）：ポータルサイト管理の自動化、ワンクリック対応
- **O**ptimize（改善する）：継続的なスコアリングと改善提案

### 1.2 対象ユーザー

- **歯科医院 院長・経営者**
- **歯科医院 マーケティング担当者**
- **歯科コンサルタント（将来的に複数医院管理）**

### 1.3 技術スタック

| 分類 | 技術 |
|------|------|
| フロントエンド | Next.js 14 (App Router), React, TypeScript |
| バックエンド | Next.js API Routes |
| データベース | PostgreSQL |
| ORM | Prisma |
| 認証 | NextAuth.js (Credentials Provider) |
| スタイリング | Tailwind CSS |
| AI/LLM | OpenAI API (GPT-4) / Claude API |
| 外部連携 | Google Analytics Data API, Search Console API |
| スクレイピング | Puppeteer / Playwright |
| インフラ | Coolify (VPS), Docker |

#### 3.2.4 優先度の決定ロジック

| 優先度 | 条件 |
|--------|------|
| ★★★ 高 | 影響度が大きく、すぐに対応可能 |
| ★★☆ 中 | 影響度は中程度、または対応に時間がかかる |
| ★☆☆ 低 | 影響度が小さい、または長期的な施策 |

**影響度の評価基準：**
- コンバージョンへの直接影響
- 検索順位への影響
