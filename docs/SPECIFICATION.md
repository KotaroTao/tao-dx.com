## 1. システム概要

### 1.1 コンセプト

T.A.O Marketing Systemは、**歯科医院のWEBマーケティングを完全に網羅した統合マーケティングプラットフォーム**です。田尾耕太郎の約20年にわたる歯科業界マーケティングの知見を凝縮し、歯科医院経営者が最小限の労力で最大のマーケティング効果を得られるシステムを目指します。

- **T**hink（考える）：GA4・サーチコンソールのデータをAIが分析し、戦略を立案
- **A**ct（動く）：ポータルサイト管理の自動化、ワンクリック対応
- **O**ptimize（改善する）：継続的なスコアリングと改善提案

### 1.2 対象ユーザー

- **歯科医院 院長・経営者**
- **歯科医院 マーケティング担当者**
- **歯科コンサルタント（将来的に複数医院管理）**

### 1.3 技術スタック

| 分類 | 技術 |
|------|------|
| フロントエンド | Next.js 14 (App Router), React, TypeScript |
| バックエンド | Next.js API Routes |
| データベース | PostgreSQL |
| ORM | Prisma |
| 認証 | NextAuth.js (Credentials Provider) |
| スタイリング | Tailwind CSS |
| AI/LLM | OpenAI API (GPT-4) / Claude API |
| 外部連携 | Google Analytics Data API, Search Console API |
| HP解析 | Cheerio（自院HPのみ） |
| インフラ | Coolify (VPS), Docker |

## 3. 機能詳細

### 3.1 【機能①】スコアリングダッシュボード

歯科医院のWEBマーケティングを8つの観点から評価し、それぞれ100点満点でスコアリング表示。
**全てAIが自動評価し、属人性ゼロを実現。**


## 7. 田尾耕太郎ノウハウ集（AIプロンプト用）

### 7.1 歯科医院SEOの鉄則

```markdown
## 歯科医院SEOの基本原則（田尾メソッド）

### 1. 地域キーワード戦略
- タイトルタグには必ず「地域名 + 診療科目」を含める
- 例: 「渋谷の歯医者｜〇〇歯科クリニック - インプラント・矯正」
- 地域名は最寄り駅名も含める（徒歩圏内すべて）

### 2. E-E-A-Tの強化
- 院長の経歴・資格を詳細に記載
- 症例写真は必ず掲載（Before/After）
- 学会発表・論文・セミナー登壇実績を掲載
- スタッフ紹介で専門性をアピール

### 3. コンテンツの網羅性
- 各診療科目ごとに独立したページを作成
- 1ページ2,000文字以上を目安
- 患者の不安・疑問に答える内容
- よくある質問（FAQ）を充実させる

### 4. 内部リンク構造
- トップ → 診療科目 → 詳細ページ の3階層
- パンくずリストを必ず設置
- 関連ページへの内部リンクを適切に配置

### 5. 更新頻度
- ブログは最低週1回更新
- お知らせは月2回以上更新
- 季節に合わせたコンテンツ（花粉症と歯の関係など）
```

### 7.2 MEO対策の要点

```markdown
## MEO対策の基本原則（田尾メソッド）

### 1. 情報の完全性
- すべての項目を100%入力（空欄を作らない）
- 説明文は750文字フルに活用
- 属性情報をすべて設定

### 2. 写真戦略
- 外観: 昼・夜・各方向から
- 内観: 待合室・診療室・設備
- スタッフ: 集合写真・個人写真
- 施術: 症例写真（許可取得済み）
- 写真は毎月追加（理想は週1枚）

### 3. 投稿の活用
- 週1回以上の投稿
- 内容: お知らせ・健康情報・イベント
- 写真付きで投稿
- CTAボタンを活用

### 4. 口コミ戦略
- 満足した患者さんへの口コミ依頼の仕組み化
- 会計時にQRコードカードを渡す
- 口コミへの返信は24時間以内
- ネガティブ口コミも誠実に返信

### 5. サイテーション
- 主要ポータルサイトへの登録
- NAP情報（Name, Address, Phone）の統一
- 地域メディアへの露出
```

### 7.3 コンバージョン最適化

```markdown
## コンバージョン最適化の基本原則（田尾メソッド）

### 1. 予約導線の最適化
- 電話番号はヘッダーに固定表示
- スマホでタップで発信可能に
- WEB予約ボタンは右下に固定
- LINEも併用（若年層向け）

### 2. フォーム最適化
- 項目は最小限（名前・電話・希望日時・症状のみ）
- 確認画面は不要（離脱の原因）
- 送信後の自動返信メールを設定

### 3. 信頼感の醸成
- 院長写真・経歴を目立つ位置に
- 患者の声を掲載（写真付きが理想）
- 各種認定・資格のバッジ表示
- 感染対策への取り組みを明記

### 4. 不安の解消
- 料金の目安を明記
- 保険適用の有無を明記
- 痛みへの配慮を説明
- 初診の流れを説明
```
